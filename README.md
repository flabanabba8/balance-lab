# Balance Lab

Compare game tuning under repeatable seeds. For a trusted local Packet Storm source workspace, provide two RON tuning files, a starting seed, trial count and simulated-time limit. The plugin copies the simulation crate into a temporary workspace, builds it with one offline Cargo worker, and runs the actual game simulation for matching seeds under a 55-second overall bound. Its owned process group is stopped on interruption. It reports each run's survival time, level, breaches and collateral, paired time differences, and source/tuning fingerprints. The original game project and tuning files are not intentionally modified.

The automated bot in this adapter stands still and chooses the first offered card; it is a repeatable stress case, not a human playtest or a complete balance judgment. The adapter targets the Packet Storm simulation API and workspace shape represented by the supplied project. It requires Rust/Cargo and its dependencies already cached. Cargo's offline mode prevents Cargo dependency downloads, but build scripts are trusted code and are not network-sandboxed; only use a project you trust. The source copy and compiled binary are temporary and are not included in the plugin. A real local Packet Storm simulation ran for two matching seeds with identical tunings. In a second small test, reducing server integrity changed survival time for both paired seeds. Broader scenarios and human gameplay remain unverified.

A separate built-in toy duel model compares two configurations with paired random rolls, timeouts and a paired standard error. It is not a simulation of Packet Storm or any specific game. Synthetic tests cover both the math and isolated source-copy behavior. Validate any proposed balance change against real gameplay.
